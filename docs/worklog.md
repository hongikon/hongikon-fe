## 2026-11-09 · 근처 알림: 같은 가게 다시 알림을 하루 1번에서 '다시 온 방문 + 3시간'으로

- (사용자 결정) 같은 가게를 하루 1번만 알리던 것을 바꿈. 시간만 보면(2~3시간마다) 가게 바로 옆에 오래 있는 사람(위층 자취방·옆 가게 근무)이 하루 종일 받으므로, 머무는 동안은 다시 알리지 않고 나갔다가 다시 들어온 방문이 지난 알림에서 3시간 지났을 때만 다시 알린다(점심·저녁에 같은 가게를 찾으면 두 번).
- `rules.ts`: `SAME_PARTNER_COOLDOWN_MS`(3시간)와 `alertedRecently(가게, 방문 시작, 보낸 기록)` 하나로 판단 — `decideOnEnter`(사유 `partnerToday` → `partnerRecent`), `alertGroup`(묶음에서 빼기), `alertableTargetIds`(GPS 로 잴 곳) 셋이 같은 함수를 쓴다. 간격은 방문 시작 기준이라 날이 바뀌어도 3시간 안이면 안 보낸다. 흔들림으로 3분 안에 다시 들어온 것은 같은 방문(`stayStartedAt`)이라 새 방문으로 치지 않는다.
- 그대로: 하루 3번, 알림 사이 30분, 밤 설정, 현장 테스트 앱의 5분 반복(`perVisit`).
- 문구: 설정 근처 제휴 안내, 업데이트 내역 1.1.0 항목, 출시·제출 문서 표.
- 확인: tsc, 테스트 93/93(같은 가게 2시간 30분 뒤 안 보냄·3시간 뒤 보냄·자정 넘김·계속 앉아 있으면 안 보냄, 엔진 점심→1시간 55분 뒤 재방문 안 보냄→저녁 보냄, GPS 대상). JS 만 바뀌어 OTA 가능.
