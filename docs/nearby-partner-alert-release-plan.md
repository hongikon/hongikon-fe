# 근처 제휴 알림 — 고도화와 출시 계획 (2026-10-31)

기획은 `nearby-partner-alert-plan.md`, 구조는 `nearby-partner-alert-impl-plan.md`에 있다. 이 문서는 TestFlight 현장 테스트(1.0.1 build 20) 뒤에 남은 일을 다룬다. 남은 일은 두 가지다. 운영 앱의 설정에서 이 기능을 어떻게 제공할지, 그리고 무엇을 더 다듬을지다.

## 1. 지금 어디까지 왔나

| 영역 | 상태 | 위치 |
|---|---|---|
| 앱 판단 로직 | 20m 알림 반경. 100m 지오펜스로 깨운 뒤 정밀 GPS로 거리를 잰다(최대 2시간). 5분 머물면 알림. 여러 곳이면 "근처 N곳" | FE `feature/nearby-partner-alert` `fc81738`(로컬, push 안 함) |
| 설정 화면 | 설정 > 알림 > "근처 제휴 알림". 로그인한 사람에게만 보인다. 켜기, 소속 선택, 수신 동의, "항상 허용" 안내, 개인정보 안내가 있다 | `NearbyAlertSettings.tsx` |

## 2. 설정에서 제공하는 구조

### 2-1. 세 겹 스위치

사용자가 켜도, 아래 셋이 모두 켜져야 알림이 간다. 문제가 생기면 위쪽부터 끈다.

```
① 서버 긴급 스위치 nearbyAlertsEnabled (운영진, 즉시 전체 끄기)
   └ ② 업체별 nearby_alert (관리자 화면 > 제휴 > "근처 알림 대상")
       └ ③ 사용자 설정 (설정 > 근처 제휴 알림 켜기 + 수신 동의 + 위치 "항상")
```

- 정할 것: 긴급 스위치를 properties(바꾸면 재배포)로 둘지, 관리자 화면 토글로 둘지. **관리자 토글을 추천한다.** 오탐 신고가 들어오면 몇 분 안에 꺼야 하기 때문이다.

### 2-2. 설정 화면 구성 (운영판)

| 칸 | 지금 | 운영판 제안 |
|---|---|---|
| 켜기/끄기 | 있음 | 그대로. 끄면 지오펜스와 GPS 작업을 바로 멈춘다 |
| 내 소속 | 있음(선택, 없으면 총학생회만) | 그대로 |
| 상태 줄 | 권한·서버 상태를 문장으로 보여 줌 | "알림이 오려면" 점검표로 바꾼다(알림 권한 ✓ / 위치 항상 ✓ / 정밀 위치 ✓ / 운영 중 ✓). 빠진 칸 옆에 "고치기" 버튼 |
| 빈도 | 고정(같은 가게 하루 1번, 하루 3번, 30분 간격) | 고정 유지(10-31 사용자 결정: 선택지 없음) |
| 받지 않을 시간 | 없음(10-29에 고정 금지 시간대를 뺌) | **선택 추가:** "밤 10시~아침 8시에는 받지 않기", 기본 켜짐 |
| 가게별 끄기 | 없음 | 알림 버튼 "이 가게 알림 그만 받기" + 설정에 "알림 안 받는 가게" 목록(기기에만 저장) |
| 수신 동의 | 켤 때 한 번 | 그대로. 끄면 동의 철회로 서버 시각 삭제. 2년마다 다시 안내(법 확인 결과에 따라) |
| 개인정보 안내 | "항상 허용" 화면 안 박스 | 설정 맨 아래에도 한 줄: "위치는 휴대폰 안에서만 써요" + 처리방침 링크 |

### 2-3. 누가 볼 수 있나

- 로그인한 사람만 본다(지금과 같음). 수신 동의 시각을 서버에 남겨야 하기 때문이다.
- 긴급 스위치가 꺼져 있으면 칸은 보이되 "잠시 멈췄어요"를 띄운다. 칸을 숨기면 심사관이 "항상" 위치 권한을 쓰는 기능을 찾을 수 없다.

### 2-4. 처음 알리는 길

설정 깊숙이 있으면 아무도 켜지 않는다. 대신 강요하지 않게 한 번씩만 알린다.
- 제휴 시트 아래에 한 줄: "이 가게 근처에 있을 때 알려 드릴까요? 설정하기" (한 번 닫으면 다시 안 띄움)
- 업데이트 소식(변경 기록)에 한 번 소개
- 첫 실행 안내에는 넣지 않는다. 처음부터 "항상" 위치를 묻는 건 거절률이 높고, 유도로 보일 수 있다.

## 3. 고도화 후보

| # | 내용 | 효과 | 배포 |
|---|---|---|---|
| 1 | **Android 포그라운드 서비스**: 정밀 GPS 20m 판단을 Android에서도(지금은 100m로 대신) | Android 오탐 감소 | 네이티브 |
| 2 | **알림 버튼**: "이 가게 그만", "오늘은 그만" | 귀찮을 때 기능 전체를 끄지 않게 | 네이티브(알림 카테고리) |
| 3 | **앱 안 "지금 근처 제휴 N곳"**(기획 2단계): 지도를 열면 거리순 목록 | "앱 사용 중" 권한만 준 사람도 쓴다 | 네이티브(같은 빌드) |
| 4 | 여러 곳 목록에 거리 표시, 지도를 그 가게들이 다 보이게 맞추기 | 고르기 쉬움 | OTA |
| 5 | 알림 문구에 혜택 조건(시간·최소 금액) 요약 | 매장에서 헛걸음 줄임 | OTA |
| 6 | **익명 효과 집계**: 알림 탭 수, 기능을 끈 수를 날짜·가게별 숫자로만 집계(사용자·위치 없음) | 성공 기준(탭률·끈 비율)을 잴 수 있음 | BE + OTA |
| 7 | 배터리: 정밀 GPS 2시간 상한과 정확도 설정을 실측해 조정 | 배터리 불만 예방 | OTA |

추천 순서는 1·2·3을 다음 네이티브 빌드에 한꺼번에, 4·5·7은 OTA로, 6은 서버와 함께다.

## 5. 출시 순서 제안

1. BE 머지와 운영 반영. 스위치는 꺼짐, 업체는 0곳.
2. 운영 네이티브 빌드(2.0, 새 runtime)를 낸다. 근처 알림 코드, 고도화 1·2·3, 권한 문구가 들어간다. 운영 빌드에서는 현장 테스트 기능이 빠진다.
3. 심사: App Store와 Play 비공개 트랙. Play가 거절하면 Android는 3번(앱 안 목록)까지만 낸다.
4. 처리방침 공지(7일) 뒤 적용일에 긴급 스위치를 켜고, 학교 앞 몇 곳만 `nearby_alert`를 켠다.
5. 2주 동안 6번 집계를 보고 업체를 넓힌다.

## 7. 테스트 앱에서 확인하는 순서 (TestFlight 1.0.1, 10-31 빌드)

설정 > 알림 > 근처 제휴 알림. 줄을 누르면 창이 열린다. 테스트 앱에는 창 맨 아래 [테스트] 칸이 더 있다.

| # | 확인할 것 | 하는 법 | 기대 |
|---|---|---|---|
| 1 | 켜기 흐름 | 꺼진 상태에서 줄 누름 → 동의 체크 → 켜기 → "항상 허용" 안내 → 시스템 창 | 안내 화면의 "켜지 않을게요"로 빠져나올 수 있다. 켜면 창이 닫히고 줄에 소속이 보인다 |
| 2 | 점검표 | 휴대폰 설정에서 위치를 "앱 사용 중"으로, 또는 정확한 위치를 끄고 앱으로 돌아옴 | 줄에 "확인 필요", 창의 점검표에 주황 표시와 고치기 버튼. 고치고 돌아오면 초록 |
| 3 | 시험 알림(걷지 않고) | [테스트] 시험 알림 "가게 한 곳" → 홈 화면으로 나가 5초 | "○○에 계신가요?" 알림. 누르면 그 가게 시트 |
| 4 | 묶음 알림 | "여러 곳 묶음" | "근처에 제휴 가게가 3곳 있어요". 누르면 목록 |
| 5 | 알림 버튼 | 시험 알림을 길게 누름(또는 아래로 당김) | "이 가게 알림 끄기". 누르면 앱이 열리며 안내 창 |
