# 물어보기로 앱 조작하기 — 계획 (11-07)

운영진 요청(11-07):
- "~~가 어디야"를 물으면 그 건물을 지도에 바로 핀으로 찍고, 위에 짧은 설명을 팝업이나 모달로 띄운다.
- 각종 설정도 물어보기로 바꿀 수 있게 한다.

## 지금 있는 것

- **지도 요청 통로:** `src/lib/mapIntents.ts`. 다른 화면이 지도 탭에 한 번짜리 요청을 넘긴다. 지금 있는 요청은 `focusReport`, `focusPartner`, `previewLocation` 등이다. 지도 탭은 포커스될 때 요청을 꺼내 처리한다(`MapScreen.handleMapIntent`).
- **건물 선택:** `MapScreen`의 `setSelectedBuilding`이 건물 시트를 연다. 검색에서 고를 때와 같은 흐름이다.
- **서버 답의 근거:** 답의 `sourceIds`에 `building:…`, `facility:…`, `partner:…`가 들어온다(AskLlmClient 규칙).
- **설정:** `SettingsContext`에 다음 함수가 있다. 함수를 부르면 서버 동기화까지 처리된다.
  - `toggleSubscriptionAlert`: 알림 전체
  - `toggleAlertCategory`: 공지·장학·행사·수강·시설·취업·상담
  - `toggleSubscribedDept`, `toggleDeptAlert`: 게시판 구독, 게시판 알림
  - `toggleReportStatusAlert`, `toggleNewReportAlert`: 제보 알림

## 1. 지도 바로가기

1. 서버가 답과 함께 `actions`를 보낸다. 예: `{ type: 'map', target: 'building:T', label: 'T동(제4공학관)', summary: '컴퓨터공학과 멀티미디어실 T604 — 6층' }`
   - 질문이 위치를 묻는 경우에만 보낸다(어디, 위치, 몇 층, 가는 길 등). 그리고 답이 실제로 쓴 근거 중 `building`, `facility`, `partner`가 있을 때만 보낸다.
   - LLM이 좌표를 만들어 내지 않는다. 앱 데이터에 있는 건물 id만 쓴다.
   - 앱 안 흐름(askAnswers)으로 답할 때도 건물을 알면 같은 `actions`를 붙인다.
2. 앱에 `mapIntents`에 `focusPlace` 요청을 하나 더한다. 처리 순서:
   1. 지도 탭으로 옮긴다.
   2. 그 건물(또는 시설·제휴처)을 가운데에 놓고 핀과 시트를 띄운다.
   3. 지도 위쪽에 설명 카드를 띄운다. 카드에는 summary 한두 줄, [닫기], [물어보기로 돌아가기] 버튼을 둔다.
3. **동작 방식(11-07 결정):** 답에 [지도에서 보기] 버튼을 두고, 누르면 이동한다. 자동으로 넘어가지 않는다.

## 2. 설정 바꾸기

- **원칙(11-07 결정, 확인 버튼 카드):** 물어보기가 스스로 바꾸지 않는다. "공지 알림 꺼 줘"를 알아들으면 [공지 알림 끄기] 확인 버튼이 있는 카드를 띄우고, 학생이 눌러야 바뀐다. 잘못 알아들어도 아무것도 바뀌지 않는다.
- **알아듣기:** 앱 안에서 정해진 말로 판단한다(LLM 없음, 비용 없음). 예: 알림 켜/꺼, ○○ 알림, ○○ 게시판 구독, 제보 알림.
- **카드로 바꿀 수 있는 것:**
  - 알림 전체 켜고 끄기
  - 분야별 알림(공지·장학·행사·수강·시설·취업·상담)
  - 게시판 구독과 해제(학과 이름으로), 게시판별 알림
  - 내 제보 결과 알림, 캠퍼스 새 제보 알림
  - 저장한 소식 보기
- **바꾸지 않고 그 화면을 열어 주기만 하는 것:**
  - 위치 권한, 근처 제휴 알림(동의가 필요해 학생이 직접 그 화면에서)
  - 로그아웃, 탈퇴, 약관, 처리방침, 내 제보 내역, 공지사항
- **화면 열기:** 설정 안의 해당 화면으로 바로 간다. 예: "탈퇴 어떻게 해" → [탈퇴 화면 열기]

## 개인정보와 법

- 새로 모으는 정보는 없다. 조작은 앱 안에서 이미 있는 함수를 부르는 것뿐이다.
- 질문은 지금처럼 물어보기 기록에 남는다(가림 처리).
- 동의가 필요한 설정(위치, 근처 알림)은 물어보기로 켜지 않는다. 동의는 학생이 직접 그 화면에서 해야 한다.

## 순서

1. 지도 바로가기
   - 서버: `actions`
   - 앱: `focusPlace` 요청, 지도 위 설명 카드
   - 평가셋: 위치 질문 → 건물 id
2. 설정 카드: 앱 안 판단과 확인 카드
3. 화면 열기

서버 응답에 필드를 더할 뿐이라 옛 앱은 그대로 동작한다. 앱 쪽 기능은 1.1.0 물어보기 탭과 함께 나간다(OTA 가능, 네이티브 빌드 필요 없음).
