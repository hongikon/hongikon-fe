# 물어보기 — 과목 DB·학년별 이수체계·줄임말 계획 (11-10)

운영진 요청(11-10):
- 학교 과목·시설 줄임말이 잘 안 먹는다. 예: 중앙동아리 → 중동, 교환학생 → 교환, 방문학생 → 방문, 컴퓨터프로그래밍 → 컴프, 인터넷프로그래밍 → 인프.
- 학과별로 1학년 때 무슨 과목을 듣는지 같은 교육이수체계를 (사진으로도) 보여 주면 좋겠다.
- 과목 전체를 DB 로 넣고 싶다.

## 1. 지금 있는 것 (11-10 조사)

| 무엇 | 어디 | 상태 |
|---|---|---|
| 줄임말 | BE `AskGlossary`(2개 — 교환학생, 학년 다시 다니기), FE 주제표 `match` 낱말(주제마다 손으로) | 묶음 규칙·사전 없음. 지도 데이터 `buildings`·`facilities` 에 별칭 칸이 없다(이름에 글자 그대로 있을 때만 맞음) |
| 과목 | FE `scripts/ask/data/pages-curr_*.json` | 2026 교과과정책자에서 필수·공통 과목만 손으로 옮김 — 학수번호 392개 |
| 교과과정책자 | `scripts/ask/cache/curriculum/curr.pdf`(237쪽, 컴퓨터공학과 게시판 첨부 — `sites/curriculum.py` PDF_URL) | pypdf 로는 글자 순서가 섞여 손으로 옮겨 왔다 |
| 학과 이수체계도 그림 | 학과 홈페이지 | 수집된 학과 홈페이지 쪽 중 '이수체계·로드맵'은 2곳뿐(신소재 개설과목, 기계 이수계통도) |
| 답에 그림 | 앱 답 모양(`AskSection`) | 그림 칸이 없다(목록·표만) |

**책자 표는 기계로 읽힌다**(11-10 시험, `pdfplumber`): 237쪽 중 209쪽에 표, 행 3,565개.
학과 교과과정 표는 머리가 `이수구분 | 교과목 | 학수번호 | 1학기(학점·시수) | 학수번호 | 2학기(학점·시수) | 비고` 로 같고, 쪽마다 '○○전공 1학년'처럼 학과·학년이 적혀 있다.
다만 한 칸에 여러 과목이 줄바꿈으로 들어 있어(예: `대학수학(1)\n대학수학(2)\n…`, 학수번호·학점도 같은 순서로 줄바꿈) 줄을 맞춰 나눠야 하고,
'부학기'·'택1'·두 과목 한 줄('대학물리(1), 대학물리실험(1)' ↔ '012101,012103') 같은 예외가 있다. 쪽마다 학기 합계 행(예: 16·25학점)이 있어 검산에 쓴다.

## 2. 만들 것

### 2-1. 과목 DB — `ask/courses.json`(BE 리소스, 공개 정보만)

칸: `code`(학수번호) · `name` · `dept`(개설 학과·전공) · `grade`(학년) · `term`(1·2·매학기) · `credits` · `hours` · `category`(이수구분: 기본소양·전공필수·전공선택·MSC …) · `note`(택1·설계학점 등) · `aliases`(줄임말) · `src`(책자 쪽).

1. 추출: FE `scripts/ask/sites/courses.py` — `pdfplumber` 로 학과 표를 읽고 줄바꿈 칸을 같은 순서로 나눠 과목 행으로.
2. 검사(자동): 학수번호 6자리·학점 숫자, **쪽마다 학기 합계 = 과목 학점 합**, 같은 학수번호의 과목명이 학과마다 같은지.
   합계가 안 맞는 쪽은 사람이 PDF 쪽을 보고 고친다(지금 손으로 옮긴 392개와도 대조).
3. 서버 도구 `search_courses(query, dept?, grade?)` — 과목명·줄임말·학수번호로 찾고, 학과·학년이면 그 학년 과목 표를 준다.
4. 매년 새 책자가 나오면 같은 스크립트로 다시 만든다(책자 해시가 바뀌면 다시 돌림).

### 2-2. 학년별 이수체계 — 표로 먼저, 그림은 2단계

- **표(바로 됨)**: '컴공 1학년 뭐 들어?', '화공 2학년 2학기 전공필수' → `search_courses` 결과를 답 표(학기 | 과목 | 학점 | 이수구분)로. 답 표 40행 상한 안에 들어간다.
- **그림(2단계)**: 책자의 그 학과 쪽을 그림(PNG)으로 만들어 답에 붙인다.
  - 앱: 답 모양에 그림 칸(`image: { url, alt, source }`) — 누르면 크게 보기. 앱 OTA 필요.
  - 서버: 학과별 쪽 그림을 정적 파일로(학교 공개 책자, 출처 링크를 함께). 개인정보 없음.
  - 학과 홈페이지에 이수체계도 그림이 따로 있는 학과(기계 등)는 그 그림 주소를 우선.

### 2-3. 줄임말 — 사전 + 규칙으로 후보 자동 생성 + 운영진 확인

1. **사전** `ask/aliases.json`(BE·FE 함께 씀): `{ "중동": "중앙동아리", "교환": "교환학생", "학관": "학생회관", "중도": "중앙도서관", "컴프": "컴퓨터프로그래밍", … }`.
   - FE 주제표 `match`(앱 안 안내)와 BE 분류·검색(질문을 넓혀 찾기)에 같이 쓴다.
2. **규칙으로 후보 만들기**(운영진이 알려 준 방식):
   - 뜻 단위 첫 글자: 중앙+동아리 → 중동, 논리적사고+글쓰기 → 논사글, 컴퓨터+프로그래밍 → 컴프, 인터넷+프로그래밍 → 인프, 전공기초+영어 → 전기영.
     과목 DB 의 과목명을 뜻 단위 사전(컴퓨터·프로그래밍·데이터·구조·시스템·설계·디자인·기초·영어·글쓰기 …)으로 나눠 후보를 만든다.
   - 꼬리 빼기: '학생'·'제도'·'신청'을 뗀 말(교환학생 → 교환, 방문학생 → 방문).
   - 시설·건물: '제4공학관 T동' → 'T동'·'4공'·'제4공학관', '중앙도서관' → '중도'.
3. **겹침**: 같은 줄임말이 둘 이상(인프 = 인터넷프로그래밍? 인공지능프로그래밍?)이면 사전에 둘 다 두고, 물어보기는 "어느 과목이에요?"로 되묻는다.
4. **확인**: 후보는 `reviewed` 칸을 비워 두고 운영진이 맞는 것만 켠다(학생들이 실제로 쓰는 말인지는 사람이 안다).

## 3. 순서와 크기

| 단계 | 내용 | 확인 |
|---|---|---|
| 1 | 줄임말 사전 1차(운영진 예시 + 특성화교양·시설·건물) + FE·BE 연결 | 질문 길 찾기 시험에 줄임말 문항 추가 |
| 2 | 과목 DB 추출·자동 검사(합계 대조) | 합계 안 맞는 쪽 목록 → 사람이 확인 |
| 3 | `search_courses` 도구 + '○○과 ○학년 과목' 표 답 | `place.json` 처럼 시험 문항(학과·학년별) |
| 4 | 과목명에서 줄임말 후보 자동 생성 → 운영진 확인 | 겹침 목록 |
| 5 | 학과 쪽 그림 + 앱 그림 칸(OTA) | 테스트앱에서 확인 |

## 4. 남는 것

- 실제 이번 학기 개설 과목(분반·교수·시간)은 수강신청 시스템에 있다 — 로그인이 필요하면 가져오지 않는다. 책자는 '교육과정'이지 '이번 학기 개설'이 아님을 답에 밝힌다.
- 책자는 2026학년도 것. 입학연도마다 교육과정이 다를 수 있어(책자 '적용원칙') 답에 '2026 교과과정 기준'을 붙인다.
