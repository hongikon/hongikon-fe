# 설정 탭 UI 개선안 — 토스·당근마켓 기준

`SettingsScreen.tsx` 현재 코드를 기준으로 진단했다. 토스·당근마켓처럼 "잘 만든 국내 앱"의 설정 탭이
공통으로 갖는 특징을 기준선으로 삼고, 지금 화면과 차이 나는 지점을 우선순위별로 정리했다.

## 1. 벤치마크: 토스·당근마켓 설정 탭이 공통으로 하는 것

두 앱 다 정보 구조(로그아웃·계정 관리·알림·일반)는 지금 우리 앱과 거의 같다. 차이는 항상
**디테일**에서 난다:

1. **프로필 카드가 리스트 맨 위, 리스트와 다른 톤으로 떠 있다.** 일반 행(row)이 아니라 아바타 +
   이름/닉네임 + chevron으로 된 카드 하나가 "이게 나"라는 걸 바로 알려준다.
2. **그룹은 모서리가 둥근 카드다.** 화면 끝까지 붙는 플랫 리스트가 아니라, 좌우 여백을 두고
   카드마다 `radius: 12~16`, 옅은 그림자 또는 `1px` 보더로 분리한다.
3. **토글·버튼 전환에 애니메이션이 있다.** 스위치 썸이 순간이동하지 않고 스프링으로 슬라이드한다.
   토스는 여기에 haptic까지 얹는다.
4. **위험한 동작(로그아웃·탈퇴)은 시각적으로 격리된다.** 목록 중간에 빨간 텍스트로 섞어두지 않고,
   화면 맨 아래 별도 블록으로 빼거나 최소한 위아래 여백을 크게 둬서 "실수로 누르기 어렵게" 만든다.
5. **섹션 제목이 캡션이 아니라 짧은 헤딩이다.** 10px 회색 라벨보다 조금 더 크고 진한 텍스트를 써서
   "여기부터 새 그룹"이라는 게 스캔할 때 바로 보인다.
6. **행 터치 피드백이 명확하다.** `opacity` 감소만이 아니라 살짝 배경색이 들어오는 느낌.
7. **일관된 4/8px 그리드.** 패딩·갭 값이 임의의 숫자(13, 17 같은)가 아니라 배수로 정렬돼 있어
   리스트가 "맞춰져 있다"는 인상을 준다.

## 2. 지금 화면 진단 (`SettingsScreen.tsx` 기준)

| 항목 | 현재 | 문제 |
|---|---|---|
| 계정 섹션 | `LinkRow` 하나로 "카카오 계정으로 로그인됨" 텍스트만 (L121) | 아바타도, 닉네임도 없다. 로그인 여부만 알려주는 라벨이지 "내 정보" 느낌이 없다 |
| 섹션 컨테이너 | `section: { backgroundColor: white, marginBottom: 8 }` (L299), radius·shadow 없음, 화면 끝까지 꽉 참 | 카드가 아니라 iOS 기본 Settings.app 같은 밋밋한 리스트 |
| 토글 스위치 | `toggleThumbOn: { alignSelf: 'flex-end' }` (L349) — `Animated` 미사용, 레이아웃으로만 좌우 전환 | 켜고 끌 때 썸이 순간이동한다. 두 벤치마크 앱 다 여기 정성을 가장 많이 들이는 부분이라 티가 많이 남 |
| 위험 동작 배치 | 로그아웃(L122)·회원탈퇴(L123)가 계정 카드 안에 나란히, 설정 초기화(L222)는 "일반" 섹션 맨 밑 문의하기 바로 아래 | 탈퇴가 로그아웃과 시각적으로 동급, 초기화는 문의하기와 섞여 있어 위험도가 안 느껴짐 |
| 섹션 제목 | `fontSize: 10, color: textTertiary` (L300-307) | 그룹 구분은 되지만 헤딩이라기보다 캡션에 가까워 화면을 훑을 때 잘 안 걸림 |
| 행 터치 피드백 | `TouchableOpacity` 기본 opacity만 (L281) | 존재감이 약하다 |
| 앱 버전 행 | 정적 텍스트만 (L204), 최신 여부 표시 없음 | 마침 다른 세션에서 `expo-updates`(OTA) 작업 중이니, 붙이면 "새 버전 있음" 배지를 자연스럽게 얹을 수 있는 자리 |
| 공지사항 위치 | "일반" 섹션 맨 위(L196-200), 앱 버전·학교 정보 등과 같은 급 | 공지사항은 빈도 높은 진입점인데 일반 설정 항목들과 구분 없이 묻혀 있음 |

## 3. 개선 항목 (우선순위순)

### 🟢 바로 할 수 있는 것 (스타일 값 조정, 새 컴포넌트 불필요)

1. **섹션을 카드로 바꾼다.**
   `section`에 `marginHorizontal: 12`, `borderRadius: 14`, 그림자(`shadowOpacity: 0.04~0.06`,
   `shadowRadius: 6`, Android는 `elevation: 1`) 추가. `row`의 `borderBottomColor`도 카드 안에서는
   더 옅게(`#F7F7F7`) 낮추거나, 마지막 행엔 보더를 아예 없앤다.
2. **섹션 제목을 헤딩답게.** `fontSize: 10` → `13`, `color: textTertiary` → `textPrimary`,
   `fontFamily: FONTS.semibold`로. letterSpacing은 유지해도 좋지만 지금처럼 아주 작은 캡션
   톤에서는 벗어난다.
3. **위험 동작 분리.**
   - "설정 초기화"를 "일반" 섹션에서 빼서 화면 맨 아래(브랜드 푸터 바로 위) 독립 블록으로.
   - "회원 탈퇴"를 "로그아웃" 밑에 바로 붙이지 않고 `marginTop`을 줘서 한 박자 떨어뜨리거나,
     아이콘 없는 텍스트 링크로 격을 낮춘다(토스가 탈퇴를 항상 이렇게 다룬다).
4. **행 터치 피드백 보강.** `TouchableOpacity`의 `activeOpacity`를 0.6 정도로 낮추거나,
   `Pressable` + `android_ripple`/`style={({pressed}) => ...}`로 눌렀을 때 옅은 배경색
   (`#FAFAFA` 정도)이 잠깐 들어오게 한다.
5. **4/8px 그리드 정리.** `paddingVertical: 13` → `12` 또는 `14`, 그 밖에 어중간한 값들을
   4의 배수로 맞춘다. 시각적으로 크게 티는 안 나지만 리스트 전체 리듬이 맞아떨어진다.

### 🟡 컴포넌트 하나 더 필요한 것

6. **계정 섹션 → 프로필 카드.**
   로그인 상태일 때 "카카오 계정으로 로그인됨" 한 줄 대신, 카카오 프로필 이미지(있다면)나
   기본 아바타 + "홍익인" 같은 표시 이름 + chevron으로 된 카드형 헤더 하나를 리스트 맨 위,
   다른 섹션과 다른 톤(예: `COLORS.primary`를 살짝 tint로 쓴 배경)으로 얹는다. 탭하면
   계정 정보/로그아웃/탈퇴가 모인 서브 화면으로 이동 — 지금처럼 로그아웃·탈퇴가 메인 리스트에
   바로 노출되지 않아 위험 동작 격리 효과도 같이 얻는다.
   - `AuthContext`에 카카오 프로필 이미지 URL이 아직 없다면(현재 `nickname` 정도만 있을 수
     있음), 백엔드 `CustomOAuth2User`/`KakaoUserInfo`에 이미 있는 값인지 먼저 확인.
7. **토글에 애니메이션.** `Animated.Value` 또는 `react-native-reanimated`(이미 없다면 새
   의존성)로 썸 위치를 스프링 트랜지션으로. `react-native`만으로도 `Animated.timing`으로
   충분 — 새 라이브러리 없이 가능.
8. **앱 버전 행에 상태 배지.** `expo-updates` 연동이 끝나면(다른 세션에서 진행 중인
   `UpdateBanner.tsx`와 연결) "최신 버전" / "새 버전 있음" 작은 칩을 버전 텍스트 옆에.

### 🔴 정보 구조까지 손대는 것 (선택)

9. **공지사항을 "일반" 밖으로.** 별도 섹션이나 계정 카드 바로 아래로 올려서 진입 빈도에 맞는
   위치로.
10. **"구독" + "카테고리 필터"를 한 카드로 합치기.** 지금은 흰 카드 두 개가 연달아 있는데,
    내용상 강하게 연결된 설정이라 토스식이면 한 카드 안에 서브 그룹 두 개로 묶는다.
11. **다크모드.** `app.json`이 `userInterfaceStyle: light`로 고정돼 있어 범위가 크다 —
    이번 개선 사이클엔 넣지 말고 별도 트랙으로.

## 4. 제안 순서

1번 세트(🟢)부터 — 코드 변경량 작고 리스크 없이 "만든 티"가 바로 난다.
그다음 프로필 카드(6)와 토글 애니메이션(7) — 이 둘이 토스·당근 느낌을 가장 크게 만든다.
나머지는 다른 기능(OTA 업데이트 배너, 공지사항 위치)과 일정 맞춰서.
