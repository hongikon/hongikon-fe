# 경로망 조사 v3 - 조사 담당 가이드북

현장에서 점과 간선을 찍는 사람을 위한 안내서입니다. 개발 내용은 몰라도 됩니다.
기술 설명이 필요하면 `docs/path-survey-v3.md`를 보세요.

**접속:** `https://hongikon.com/dev/path-survey-v3` (암호키 입력)
**권장 환경:** 노트북 또는 패드의 크롬. 한 번에 **탭 하나만** 여세요.

---

## 0. 시작하기 전에 꼭 알 것

1. 맨 위 **저장** 버튼만 누르면 됩니다. 이 브라우저에 저장한 뒤 서버에 **초안**으로 올라갑니다. JSON 파일을 따로 보낼 필요가 없습니다.
2. 초안은 앱 길찾기에 바로 쓰이지 않습니다. 운영 적용은 서버 탭에서 따로 합니다(아래 9장).
3. 저장 버튼 아래 줄에 서버 저장 상태가 나옵니다. 빨간 글씨("서버 저장 실패")면 그 줄을 눌러 다시 시도하세요.
4. 오류가 있어도 작업과 저장은 계속할 수 있습니다. 오류는 "나중에 고칠 곳 표시"입니다.
5. 실수해도 **Ctrl+Z**로 되돌릴 수 있습니다.
6. 서버 저장이 안 될 때를 대비해, 하루를 마칠 때 **백업 저장**으로 파일을 받아 두면 더 안전합니다(보험).

### 처음 한 번만

- 화면을 열면 서버를 한 번 확인하고, 필요하면 맨 위에 안내 상자가 나옵니다. 저절로 올리거나 불러오지는 않습니다.
  - 이 브라우저에 조사 내용이 있는데 서버에 올린 적이 없으면: "이 내용은 아직 서버에 올라가지 않았어요. 서버에 기준으로 저장할까요?" **서버에 저장**을 누르면 지금 내용이 첫 초안이 됩니다.
  - 이 브라우저가 비어 있고 서버에 초안이 있으면: **서버에서 불러오기**를 누르면 가장 최근 초안을 받아 이어서 작업합니다.
- 서버에 없는 예전 백업 파일로 이어서 작업하려면: 백업 탭의 **불러오기**에서 파일을 고르세요.
- 예전 v2 조사 파일이 있으면: **v2 변환** 탭에서 파일을 고르세요. 변환 전 상태는 자동으로 저장 지점에 남습니다.

## 1. 화면 구성

| 위치 | 이름 | 용도 |
|---|---|---|
| 맨 위 왼쪽 | **저장** 버튼 (파랑) | 브라우저에 저장 지점을 남기고 서버에 초안으로 올림. 옆에 "저장됨" 또는 "저장 필요" 표시 |
| 저장 버튼 아래 | 서버 상태 줄 | "서버 저장됨 #번호 시각", "서버에 안 올린 변경 있음", "서버 저장 실패"(빨강, 눌러서 다시 시도) 등 |
| 맨 위 오른쪽 | 오류 수, 되돌리기 | 오류 수를 누르면 점검 화면, 되돌리기는 앰버색 버튼 |
| 모드 줄 | 점 찍기 / 잇기 / 옮기기 / 여러 점 | 지금 무엇을 할지 고름 |
| 컨텍스트 바 | 외부 / 내부, 종류, 작업 층 | **앞으로 찍을 새 점**의 설정 |
| 지도 | | 점과 간선이 보임 |
| 오른쪽 | 선택한 점 시트 | **지금 선택한 점**의 정보를 고침 |

> 위쪽 컨텍스트 바는 "새로 찍을 점", 오른쪽 시트는 "이미 찍은 점"입니다. 서로 영향을 주지 않습니다.

---

## 2. 점 찍기

### 2.1 기본 순서

1. 모드에서 **점 찍기**를 고릅니다.
2. 컨텍스트 바에서 **외부 / 내부**를 고릅니다. (처음엔 외부)
3. **종류**를 고릅니다: 기본, 계단, 엘리베이터, 출입구
4. 내부라면 **건물**과 **층**을 고릅니다. (아래 2.3)
5. 지도를 누르면 점이 찍힙니다.

찍는 동안 설정은 유지됩니다. 건물이나 층을 바꿀 때만 다시 고르세요.

### 2.2 점의 모양과 색

| 모양 | 종류 |
|---|---|
| 원 | 기본 |
| 사각형 | 출입구 |
| 마름모 | 엘리베이터 |
| 삼각형 | 계단 |

- **색은 위치**입니다. 외부는 회청색, 내부는 건물마다 다른 색입니다(점 옆에 건물 글자도 표시).
- 회색 내부 점은 **건물을 아직 안 고른 점**입니다.

### 2.3 건물과 층 고르기

**건물 검색:** 검색칸에 `K`만 쳐도 K동이 나옵니다. 건물 이름(예: `조형관`, `D2`)이나 출입구 이름으로도 찾을 수 있습니다.

**층 고르기:** 건물을 고르면 그 건물의 층 버튼이 나옵니다. 여러 층을 누르면 모두 선택됩니다.

**층 범위 입력:** 층 찾기 칸에 입력하면 선택에 더해집니다. "선택 해제"로 비웁니다.

| 입력 | 결과 |
|---|---|
| `1-15` | 1~15층 |
| `B3-5` | 지하3층~5층 |
| `B3-B1` | 지하3층~지하1층 |
| `B2-3, 5, 8-10` | 섞어서 입력 |
| `L`, `1.5`, `B1.5` | L층, 중간층 |

- 지하는 **B로만** 씁니다. `-1`은 받지 않습니다.
- 건물에 없는 층을 고르면 "서버 정보에 없는 층 N개"라고 알려 주지만 선택은 됩니다. 실제로 있는 층이면 그대로 두세요.

**어떤 점에 층을 몇 개 줄까?**
- 복도, 방 같은 일반 점: **층 하나만**
- 엘리베이터: 서는 층 모두 (예: `1-9`)
- 계단: 이어지는 층들
- 출입구: 반드시 **층 하나만**

### 2.4 이어 찍기

점 찍기 모드에서 **이어 찍기**를 켜면(파랑) 새 점이 **직전 점과 자동으로 간선으로 이어집니다.** 기준점에는 파란 링이 보입니다. 걷는 길을 따라 연달아 찍을 때 켜세요. 새로고침하면 꺼집니다.

---

## 3. 출입구 넣기

건물 안과 밖은 **반드시 출입구를 거쳐** 이어야 합니다. (외부 점과 내부 점을 직접 이을 수 없습니다.)

1. 종류를 **출입구**로 두고, 건물과 층을 **하나** 고릅니다.
2. 출입구 위치를 지도에서 누릅니다. 오른쪽 시트가 바로 열립니다.
3. 서버에 있는 출입구 이름 중 맞는 것을 누릅니다. 층이 이름에 맞게 자동으로 바뀝니다.
4. 서버에 없는 출입구면 **새 이름 자동 생성**을 누릅니다. "신규/서버에 없음"이라고 표시됩니다.
5. 이름을 비워 두면 오류가 남습니다.

**이어 주는 방법**
- 바깥 길(외부 점) -> 출입구 -> 건물 안 점. 이 순서로 간선을 잇습니다.

## 4. 간선 잇기와 고치기

| 하고 싶은 일 | 방법 |
|---|---|
| 두 점 잇기 | **잇기** 모드에서 두 점을 차례로 누름 |
| 계단 구간 표시 | 간선을 누르고 종류를 **계단**으로 바꿈 |
| 간선 지우기 | 간선을 누르고 삭제, 또는 같은 두 점을 다시 이어 지움 |
| 점 위치 옮기기 | **옮기기** 모드에서 점을 끌기 |
| 길 중간에 점 끼우기 | 점을 간선 위에 끌어다 놓으면 간선이 둘로 나뉨 |

### 간선 모양

| 모양 | 뜻 |
|---|---|
| 회청색 실선 | 외부 길 |
| 건물 색 실선 | 그 건물 안의 길(출입구 포함) |
| 회색 점선 | 외부 <-> 출입구, 또는 건물과 건물 사이 통로 |
| 진한 선 + 흰 점선 | 계단 |

---

## 5. 점 정보 고치기

점을 누르면 오른쪽 시트가 열립니다.

- 외부 / 내부 전환
- 종류 변경
- 건물과 층 변경
- 출입구 이름
- 메모(선택)
- **이 점과 연결 간선 지우기**

여러 점을 한 번에 같은 건물, 층으로 바꾸려면 **여러 점** 모드에서 점들을 고르세요. 서로 다른 건물의 점이 섞여 있으면 적용 전에 확인창이 뜹니다.

## 6. 단축키 (노트북)

| 키 | 동작 |
|---|---|
| Ctrl+Z (Mac은 Cmd+Z) | 되돌리기 |
| Delete 또는 Backspace | 선택한 점 1개와 연결 간선 삭제 |
| 방향키 | 선택한 점을 조금씩 이동 |
| Shift+방향키 | 크게 이동 |
| Alt+방향키 | 아주 조금 이동 |

- 방향키를 연달아 누른 것은 되돌리기 한 번에 돌아옵니다.
- **글자를 입력하는 중에는 단축키가 동작하지 않습니다.** 검색칸에서 Backspace를 눌러도 점이 지워지지 않습니다.
- 점을 선택하지 않으면 방향키는 지도 이동입니다.

## 7. 점검 화면과 오류 고치기

위쪽 **오류 N** 또는 **점검** 탭을 누르면 목록이 나옵니다. 줄을 누르면 지도가 그 점으로 이동합니다.

- **오류**: 고쳐야 최종 파일이 완성됩니다.
- **경고**: 확인해 보세요. 의도한 것이면 그대로 둬도 됩니다.
- **참고**: 알아 두기만 하면 됩니다.

### 자주 나오는 오류와 해결

| 화면 문구(요약) | 고치는 방법 |
|---|---|
| 내부 점인데 층이 없어요 | 점을 눌러 건물과 층을 고른다 |
| 출입구 라벨이 없어요 | 점을 눌러 출입구 이름(서버 이름 또는 자동 생성)을 고른다 |
| 출입구의 건물과 층이 1개가 아니에요 | 출입구의 층을 하나만 남긴다 |
| 외부 점과 이어진 내부 점이 출입구가 아니에요 | 사이에 출입구를 넣거나, 점 종류를 출입구로 바꾼다 |
| 계단/엘리베이터 층이 2개 미만 | 서는 층을 두 개 이상 고른다 |
| 건물이 둘 이상인데 층 짝이 없어요 | 점 시트에서 "같은 높이인 두 층"을 지정한다 |
| 간선이 자기 자신 / 중복 | 해당 간선을 지운다 |
| 건물 경계 밖이에요 (경고) | 위치가 틀렸으면 옮기고, 맞으면 그대로 둔다 |
| 다른 건물을 직접 이었어요 (경고) | 건물 사이 통로라면 의도한 것이니 그대로 둔다 |

### v2에서 변환한 데이터의 "수동 확인 목록"

변환 탭의 목록(출입구, 엘리베이터, 건물 경계 안 외부 점)을 위에서부터 하나씩 처리합니다.

1. 항목을 누르면 지도가 그 점으로 이동하고 시트가 열립니다.
2. 후보 버튼을 고르면 채워지고 목록에서 빠집니다.
3. 경계 안 외부 점은 **외부 유지**(길 위의 점) 또는 **내부로 변경**(건물 안 점)을 고릅니다.

## 8. 저장과 백업 (가장 중요)

| 기능 | 언제 쓰나 |
|---|---|
| 자동 보관 | 바꿀 때마다 이 브라우저에 자동. 신경 쓸 필요 없음(서버에는 안 올라감) |
| **저장** 버튼 | 한 구간을 끝냈을 때. 되돌릴 수 있는 지점을 남기고 서버에 초안으로 올림. 내용이 그대로면 다시 올리지 않음 |
| 저장 지점 탭 | 예전 상태로 되돌리고 싶을 때 |
| **백업 저장** (보험) | 서버 저장이 안 될 때를 대비해 하루를 마칠 때 권장. JSON 파일로 받아 보관 |
| 코드 복사 (보험) | 파일 저장이 어려울 때. JSON을 복사해서 메모 앱 등에 붙여 보관 |
| Gist 동기화 (보험) | 서버를 쓸 수 없을 때 여러 기기에서 이어가는 예전 방법(선택) |

**서버 저장 상태 줄**
- "서버 저장됨 #12 14:05": 지금 내용이 서버 초안 #12와 같습니다.
- "서버에 안 올린 변경 있음": 저장 버튼을 누르면 올라갑니다.
- "서버 저장 실패: 사유. 눌러서 다시 시도"(빨강): 이 브라우저에는 저장돼 있습니다. 그 줄을 누르거나 저장을 다시 누르세요. 계속 실패하면 백업 저장을 받아 두고 개발 담당에게 알리세요.
- "브라우저에만 저장됨: 이 탭에 서버 암호키가 없어요": 탭을 닫고 주소로 다시 들어가 암호키를 넣으세요.
- "서버에 올릴 길 없음": 간선으로 이어진 점이 아직 없습니다. 실패가 아닙니다.
- 점검 오류가 있으면 뒤에 "(점검 오류 N건 포함)"이 붙습니다. 오류가 있어도 초안 저장은 됩니다.

**다른 기기에서 더 새로 올린 경우**
- 화면을 열 때: "다른 기기에서 저장한 #번호(시각, 이름)가 서버에 있어요." 안내가 나옵니다. **서버에서 불러오기**를 누르면 확인창 뒤에 그 내용으로 바뀝니다. 바뀌기 전 상태는 저장 지점에 남습니다. 이 브라우저에 서버에 안 올린 변경이 있으면 확인창 첫 줄에 따로 알려 줍니다.
- 저장할 때: 그 사이 다른 기기가 올렸으면 "그래도 이 내용으로 새 초안을 만들까요?"라고 묻습니다. 다른 사람 작업 위에 이어서 하려면 취소하고 먼저 불러오세요. 취소해도 이 브라우저 저장은 이미 되어 있습니다.

**하지 말아야 할 것**
- 브라우저의 "사이트 데이터 삭제", "쿠키와 사이트 데이터 지우기"(서버에 안 올린 변경이 사라집니다)
- 같은 화면을 탭 두 개로 여는 것(다른 탭에서 저장하면 이 탭은 저장을 멈추고, 서버에도 올리지 않습니다)
- 암호키와 토큰을 채팅, 문서, 사진에 올리는 것

**기기를 바꿀 때:** 기존 기기에서 저장 버튼 -> 새 기기에서 접속해 **서버에서 불러오기**. 서버를 쓸 수 없을 때만 백업 파일로 옮기세요.

## 9. 작업을 마치고 넘길 때

1. **점검**에서 오류를 최대한 줄입니다. (오류가 남아도 저장은 됩니다.)
2. **저장** 버튼을 누르고, 서버 상태 줄이 "서버 저장됨 #번호"인지 확인합니다.
3. 그 번호를 팀에 알려 주면 끝입니다. 파일을 따로 보낼 필요가 없습니다.
4. 운영 적용(앱 길찾기에 반영)은 서버 탭에서 합니다. 적용은 점검 오류와 경고 확인창을 읽은 뒤에 합니다. 시험용 초안은 적용하지 않습니다.

기준이 둘이라는 것만 기억하세요.
- **작업 기준**: 가장 최근 서버 초안. 모두 여기서 불러와 이어서 작업합니다.
- **운영 기준**: 서버 탭의 "운영" 버전. 앱 길찾기가 지금 쓰는 경로망입니다. 적용하면 배포나 앱 업데이트 없이 바로 바뀝니다.

서버를 쓸 수 없을 때(비상용): 백업 탭의 **경로망 내보내기** 파일과 같은 시점의 **백업 파일**을 개발 담당에게 전달합니다. 오류가 있으면 "오류 N건 포함(미완성)"이라고 표시되고, 파일 이름에 `incomplete`가 붙습니다.

## 10. 막혔을 때

| 상황 | 해결 |
|---|---|
| 화면이 비어 보임 | 맨 위 안내 상자의 **서버에서 불러오기**. 서버 탭 버전 목록의 불러오기, 저장 지점 탭, 백업 파일에도 남아 있을 수 있음 |
| 서버 저장 실패가 계속됨 | 빨간 상태 줄을 눌러 다시 시도. 계속되면 백업 저장을 받아 두고 개발 담당에게 연락 |
| 점이 안 눌림 | 층 필터가 켜져 있는지 확인(필터에 걸리지 않은 점은 흐려지고 눌리지 않음) |
| 지도가 안 뜸 | 새로고침. 계속 안 되면 개발 담당에게 연락 |
| 방금 한 작업을 취소하고 싶음 | Ctrl+Z 또는 되돌리기 버튼 (50단계까지) |
| 엉망이 됨 | 저장 지점 탭에서 이전 시점으로 복원 (복원 전 상태도 자동으로 남음) |
